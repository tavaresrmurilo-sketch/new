# Planilhas de exemplo

Arquivos fictícios para testar **Integrações → Importar planilha** (ou a etapa 3 do onboarding):

| Arquivo | Tipo detectado |
|---|---|
| `vendas-exemplo.csv` | Vendas (inclui uma linha inválida para demonstrar a rejeição) |
| `despesas-exemplo.csv` | Despesas |
| `contas-a-pagar-exemplo.csv` | Contas a pagar |

Reimportar o mesmo arquivo não duplica registros.
